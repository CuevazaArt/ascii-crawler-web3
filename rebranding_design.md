# Design Concept: Leak Runner (Web3 Rebranding Plan)

This document outlines the visual and narrative design of Leak Runner as an original Web3 arcade — not a clone of third-party arcade IP — suitable for XRPL educational demos and grant-style submissions.

## 1. Narrative & Naming

| Element | Leak Runner name | Web3 thematic concept |
| :--- | :--- | :--- |
| Player | **The Node** / **Securithon** | Pulsing pixel vault / digital wallet icon |
| Collectibles | **Drops** / **Transactions** | Micro-ledger data points worth XRP drops |
| Foes | **Exploits** / penguin swarm | Threat nodes trying to slash / liquidate the vault |
| Power-ups | **Audit Certs** / **Shields** | Temporary clearance that exposes bugs to slashing |
| Lives | **Uptime Node Health** | Restarts allowed before permadeath slashing |
| Defeat | **Slashing / Liquidation** | On-chain burn of the Node NFT on failure |

## 2. Enemy profiles (original penguins)

*   **Bitwaddle** — Relentless chase targeting the Node’s vault.
*   **Hatglide** — Predictive pathing several flaps ahead of the player.
*   **Slipkernel** — Complex tracking that uses other penguins as fulcrums.
*   **Sourceflip** — Closes from afar, scatters when stared down.

## 3. Future catalog prospects

### A. Exploit Slayer 3D
*   **Concept:** Pseudo-3D raycasted shooter through a cyberspace grid; blast security bugs with audit beams.
*   **Web3 Mechanic:** Leaderboard matches with XRPL entry stakes. Slashed bugs drop XRP.
*   **NFT Utility:** Weapon / character skins as dynamic NFTs that level on-chain.

### B. Bug Busters / Miner Wars
*   **Concept:** Turn-based tactical artillery with destructible terrain and trajectory math.
*   **Web3 Mechanic:** 1v1 / team wager lobbies (XRP in escrow; winner takes pot).
*   **NFT Utility:** Characters as XLS-20 NFTs; drown/blow-up can trigger `NFTokenBurn`.

### C. Cryptball (vertical pinball)
*   **Concept:** High-resolution pinball with gravity, flippers, and bumpers.
*   **Web3 Mechanic:** Entry fee to launch balls toward a daily high-score jackpot.
*   **NFT Utility:** Ball skins, bumper packs, flipper attributes as XLS-20 NFTs.

### D. Audit Arena (PvP fighter)
*   **Concept:** 2D pixel fighter with hitboxes, specials, and rollback netcode.
*   **Web3 Mechanic:** 1v1 escrow battles (winner claims pot minus platform fee).
*   **NFT Utility:** Fighter NFTs; losses may damage durability or burn on permadeath.

## 4. XRPL integration highlights
*   **Micropayouts:** Small XRP drop distributions via Payment Channels / claims.
*   **XLS-20 NFT Burn:** Native `NFTokenBurn` when Node Uptime Health reaches 0.
*   **Legal:** Live mainnet may charge real XRP — see `docs/LEGAL.md`. Demo Mode is simulated.
