# Design Concept: Leak Runner (Web3 Rebranding Plan)

This document outlines the visual and narrative rebranding of the prototype to eliminate copyrighted Pac-Man IP, transforming it into an original Web3 game suitable for XRPL Grant submissions (e.g. Make Waves).

## 1. Narrative & Naming Mappings

| Original Element | Rebranded Element | Web3 Thematic Concept |
| :--- | :--- | :--- |
| **Pac-Man** | **The Node** / **Securithon** | A pulsing pixel-art golden XRP coin or digital vault wallet icon. |
| **Dots** | **Drops** / **Transactions** | Small binary bits (`1`/`0`) representing micro-ledger data points worth XRP drops. |
| **Ghosts** | **Exploits** / **Bugs** | System virus threat nodes trying to slash/liquidate your wallet. |
| **Power Pellets** | **Audit Certs** / **Shields** | Security clearance seals that temporarily expose bugs to slashing. |
| **Lives** | **Uptime Node Health** | Number of restarts allowed before permadeath slashing. |
| **Character Burn** | **Slashing / Liquidation** | On-chain burning of the node NFT from the smart contract upon failure. |

## 2. Enemy Profiles (The "Ghosts" Bugs)
*   **Blinky (Red) -> Reentrancy Attack:** Relentless chasing behavior targeting the Node's coordinates directly.
*   **Pinky (Pink) -> Frontrunner:** Predictive AI trying to steer 3 steps ahead of the player's path.
*   **Inky (Cyan) -> Flash Loan Exploit:** Complex tracking behavior that alters dynamically based on other bug positions.
*   **Sybil Bug (Clyde - Orange):** Chaotic, random movement pattern.

## 3. Future Catalog Prospects

### A. Exploit Slayer 3D (Doom 1993 Clone)
*   **Concept:** A pseudo-3D raycasted shooter where the player traverses a 3D cyberspace grid, blasting security bugs (Reentrancy, Sybil, DDoS threats) with audit beams to clean the code ledger.
*   **Web3 Mechanic:** High-score leaderboard matches with automated L2/XRPL entry bets. Slashed bugs drop XRP/ETH tokens.
*   **NFT Utility:** Your weapon and character skins are dynamic NFTs that level up on-chain, improving firing rates or starting ammo capacity.

### B. Bug Busters / Miner Wars (Worms Clone)
*   **Concept:** A turn-based tactical artillery game featuring destructible 2D terrain, wind variables, and trajectory parabola math. Players fire web3-themed heavy artillery (like the "Reentrancy Bomb" or "Hard Fork Grenade").
*   **Web3 Mechanic:** 1v1 and Team vs. Team zero-sum wager lobbies (players lock XRP in escrow, winner takes all).
*   **NFT Utility:** Individual bug/worm characters are XLS-20 NFTs. If drowned or blown up, the NFT triggers native `NFTokenBurn` (permadeath). Surviving worms level up on-chain.

### C. Pinball Wizard / Cryptball (Web3 Vertical Pinball)
*   **Concept:** A vertical high-resolution pinball machine featuring realistic physics (gravity, flipper vector force, bumper elasticity).
*   **Web3 Mechanic:** Entry fee (XRP/ETH) to launch 3 balls, aiming for the daily high score jackpot (competitive zero-sum tournament pool).
*   **NFT Utility:** Custom ball skins, bumper sound packs, and flipper attributes (e.g., larger flippers or ball-saver barriers) minted as dynamic XLS-20 NFTs.

### D. Chain Fighter / Audit Arena (Web3 PvP Fighting Game)
*   **Concept:** A 2D pixel-art fighting game where players face off in real-time. Features precise hitboxes, special move combinations, and Rollback Netcode synchronization.
*   **Web3 Mechanic:** 1v1 wager battles (both players deposit XRP into escrow; the winner claims the pot minus a 3% platform fee).
*   **NFT Utility:** Fighter characters are XLS-20 NFTs. Losing a high-stakes match damages the fighter's durability, which must be repaired with XRP, or burns it on permanent defeat.

## 4. XRPL Integration Highlights
*   **Micropayouts:** Small XRP drop distributions for eaten dots processed on-chain using native XRPL accounts.
*   **XLS-20 NFT Burn:** Using the native `NFTokenBurn` payload on the ledger when Node Uptime Health reaches 0.
